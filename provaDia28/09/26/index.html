AVALIAÇÂO PRÁTICA

Programação Front-End

Sistema de Inscrição de Tecnologia

Orintações Gerais da Avaliação


Objetivo

Desenvolver um sistema web completo de
inscrição integrando formulário estruturado
em HTML5, estilização com CSS3/Flexbox e validação interativa com
JavaScript.

Orientações de Entrega

Criar uma pasta contendo index.html,
style.css e script.js (ou arquivo único
integrado).

Critérios de Avaliação

Funcionamento correto das validações, legibilidade do codigo, responsividade

Cronograma e Distribuição de Tempo Sugerida

Etapa Atividade / Descrição Tempo Estimado
Etapa 1 Estruturação HTML5 do formulário de Inscrição 45 min
Etapa 2 Estilização e Layout Responsivo com CSS3 45 min
Etapa 3 Lógica de Validação e Manipulação do DOM com JavaScript 60 min
Etapa 4 Testes Finais, Correções e Validação de Casos de Borda 30 min


Etapa 1: Estruturação HTML5

O formulário de inscrição deve conter os seguintes campos estruturados de forma semântica:

Campos de Texto e Numérico

Nome Completo: input do tipo text obrigatório (required).
Idade: input do tipo number com limite minimo de 14 anos
(min="14").

Seleções e Interesses

Turma: elemento select com opções (ex: 1 Info, 2 Info, 3 Info).
Categoria do Projeto: botões de rádio (type="radio") para
escolha única (ex: Web, Mobile, Robótica).
Interesses Adicionais: caixas de seleção (type="checkbox") para múltiplos



Etapa 2: Estilização com CSS3

Diretrizes de design e layout para criar uma interface limpa e amigável

Layout Centralizado

Utilizar Flexbox ou Grid para centralizar o
cartão de inscrição na tela com bom
espaçamento externo.

Tipografia e Cores

Fontes limpar (ex: Inter ou Arial), paleta
profissional com contraste adequados e
bordas arredondadas.

Feedback Visual

Estados de foco evidentes em inputs e
botões com transições suaves de cor e
sombra ao interagir.



Etapa 3: Lógica JavaScript e Validações

Regras obrigatorias de script que devem ser implementadas no sistema:

Validação de Envio Padrão: Interceptar o evento submit e utilizando event.preventDefault().

ção de Idade: Verificar se a idade informada é estreitamente menor que 14 anos. Caso seja, exibir mensagem jde erro amigável e bloquear o
cadastro.

Seleção obrigatoria de categoria: Garantir que um botão de radio de categoria foi selecionado antes de prosseguir.

Exibição de resumo no DOM: Criar dinamicamente um bloco de confirmação elegante exibindo todos os dados preenchidos após o sucesso da
validação.
